# REF-0051 — Kernel Public Claim and Mark Language Matrix

| Wording | Current status | Qualification |
|---|---|---|
| guided by selected Draft Kernel principles | permitted with evidence | name the principles, version, scope and known limitations |
| implements selected Draft Kernel concepts | permitted with evidence | exact concepts, version, limitations |
| uses a risk-proportionate Draft Kernel adoption approach | permitted for a bounded implementation | identify the surface, effect tiers and non-negotiable safety/privacy boundaries; no conformance implication |
| under internal review against Draft KERNEL-* | permitted | boundary, date, no approval implication |
| building evidence toward a future Profile assessment | permitted | identify incomplete evidence and make clear that no assessment decision exists |
| Kernel-inspired | discouraged/ambiguous | replace with exact concepts and scope |
| built on the MingOS Kernel | prohibited/ambiguous | may imply completeness, approval or a stable runtime dependency |
| Kernel-ready | prohibited/ambiguous | do not use |
| MingOS Kernel conforming | prohibited now | unavailable while documents are Draft and no effective assessment exists |
| MingOS certified/approved | prohibited now | no authority exists |
| Charter compliant | prohibited now | Candidate Charters and no accepted method |
| badge, seal or official mark | prohibited now | requires separate accepted decision |

## Interpretation boundary

Using selected concepts is not a claim that the whole product, organization, model provider or professional service conforms. Public wording should preserve the difference between:

1. inspiration or selective adoption;
2. an internal evidence-building process;
3. a completed formal assessment; and
4. an authorized public conformance claim.

Ordinary MingOS product iteration may remain in the first or second category for an extended period. This is compatible with flexible implementation, provided the wording is honest and hard life-safety, privacy, consent, contestability and authority boundaries are not weakened.
